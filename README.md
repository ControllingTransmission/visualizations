dnalounge-5-9-13-viz
====================

Interactive 3D visualizations using Three.js with gamepad support.

## Features

- Multiple visualization modes: grids, bars, galaxies, and shapes
- Gamepad support for navigation and control
- Keyboard controls as fallback
- WebGL-based rendering with shader effects

## Usage

Use the menu to select different visualization modes:
- **Grids**: Interactive grid patterns with rotation controls
- **Bars**: Colorful 3D bar visualization
- **Galaxies**: Navigate to space-themed visualization
- **Shapes**: Geometric shape visualization

### Controls

**Keyboard:**
- W/S or Up/Down arrows: Navigate menu
- Enter: Select menu item
- Various keys for visualization controls (see individual visualizations)

**Gamepad:**
- D-pad: Navigate menu and control visualizations
- A button: Select menu items
- Other buttons: Visualization-specific controls
